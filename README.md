# NT Grego — widget do versículo do dia

Widget Android que mostra um versículo do **Novo Testamento em grego** (SBLGNT) por dia.
Tocar no widget abre a tela dividida: **grego em cima**, **TB / NVI** embaixo (carregadas do bible.com).

- ↻ no widget: sorteia outro versículo para hoje
- ‹ › : versículo anterior/seguinte · ☀ : volta ao versículo do dia · ⚙ : trocar versões (cole um link do bible.com)
- ↗ : abre o versículo no YouVersion

**Instalar:** baixe `NTGrego.apk` na aba *Releases* deste repositório.
